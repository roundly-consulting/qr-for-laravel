# QR for Laravel

Native QR codes for Laravel: an ISO/IEC 18004 encoder with optimal segmentation, one
optimised SVG renderer, and typed payloads for otpauth 2FA setup codes, EPC SEPA credit
transfers and PAY by square — with no third-party runtime dependencies.

> **Work in progress.** The package is being built in phases; the full installation,
> configuration and usage documentation lands with the first release.

## Requirements

- PHP ^8.4 with `ext-mbstring`
- Laravel 12.x or 13.x

## Testing

```bash
composer test
```
